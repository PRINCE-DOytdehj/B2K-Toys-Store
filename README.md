# B2K Toys Store 🧸

B2K Toys Store is a responsive toy-store website created as a web development project using HTML, CSS, and JavaScript.

The website uses a clean black-and-white design with yellow accents and provides a simple shopping experience.

## 🌐 Live Website

Visit the website:

https://prince-doytdehj.github.io/B2K-Toys-Store/

## ✨ Features

- Responsive homepage design
- Product listing and product details pages
- Multiple toy categories
- Product search
- Category filtering
- Product sorting
- Add-to-cart functionality
- Shopping cart with quantity controls
- Remove products from the cart
- Demo checkout form
- Demo order tracking
- Contact form demonstration
- Mobile-friendly navigation
- Browser localStorage for demo cart and order data

## 🚀 Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For online access, visit the live GitHub Pages website.

## 📦 Deployment with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under the build and deployment settings, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish the website.

## ⚠️ Project Limitations

This is a front-end demonstration project.

- No real payment gateway is connected.
- No real delivery or courier service is connected.
- Contact messages are stored locally in the browser and are not emailed.
- Cart and demo orders use browser localStorage.
- Data stored in localStorage is not automatically synchronized between browsers or devices.
- Product information is demonstration data.

Do not enter sensitive personal or payment information.

## 🎯 Project Objective

The objective of this project is to demonstrate basic web development skills, including website structure, styling, navigation, product display, DOM manipulation, event handling, and browser-based storage.
